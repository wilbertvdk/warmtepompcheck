# Warmtepompcheck

Onderzoeksprototype: berekent uit HomeWizard-gasdata hoeveel warmte een huis verliest per graad,
en wat een (hybride) warmtepomp zou besparen. Alles rekent in de browser; alleen de plaatsnaam
gaat naar Open-Meteo voor het weer.

Live: https://warmtepomp.wilnius.nl

De bron staat in de energiemgt-repo (`warmtepompcheck/index.html`); deze repo is alleen de publicatie.
